# Install / Instalación

## English

1. Download the release zip and extract it to a **permanent** folder — e.g.
   `C:\Extensions\ai-control`. If you move or delete that folder later, the
   extension stops working.
2. Make sure `manifest.json` sits **directly** inside the folder you picked
   (if you see a single subfolder, go one level deeper — that's the right one).
3. Open `edge://extensions` or `chrome://extensions`.
4. Turn on **Developer mode** (bottom-left in Edge, top-right in Chrome).
5. Click **Load unpacked** and select the folder.
6. Click the puzzle icon 🧩 in the toolbar and pin AI Control so you can see the badge.

**Quick check:** open claude.ai (or chatgpt.com / gemini.google.com), ask
something, switch to another window. Roughly 4 seconds after it stops writing
you should get a Windows notification with a sound.

**No notification?** Windows Settings → System → **Notifications** → your
browser must be enabled, and **Focus assist** must be off (it silences banners
when you're in a full-screen app).

### Updating
Replace the folder contents, then press **↻ Reload** on the extension card.
If the version number doesn't change, you extracted into the wrong level — see
step 2.

## Español

1. Descarga el zip de la release y descomprímelo en una carpeta **permanente**
   — por ejemplo `C:\Extensiones\ai-control`. Si luego mueves o borras esa
   carpeta, la extensión deja de funcionar.
2. Asegúrate de que `manifest.json` está **directamente** dentro de la carpeta
   que elegiste (si ves una única subcarpeta, entra un nivel más: esa es la buena).
3. Abre `edge://extensions` o `chrome://extensions`.
4. Activa el **Modo de desarrollador** (abajo a la izquierda en Edge, arriba a
   la derecha en Chrome).
5. Pulsa **Cargar desempaquetada** y selecciona la carpeta.
6. Pulsa el icono del puzzle 🧩 de la barra y ancla AI Control para ver el badge.

**Comprobación rápida:** abre claude.ai (o chatgpt.com / gemini.google.com),
pregunta algo y cámbiate a otra ventana. Unos 4 segundos después de que deje de
escribir debe llegarte una notificación de Windows con sonido.

**¿No llega la notificación?** Configuración de Windows → Sistema →
**Notificaciones** → tu navegador debe estar activado, y la **Asistencia de
concentración** desactivada (silencia los avisos cuando usas una app a pantalla
completa).

### Actualizar
Reemplaza el contenido de la carpeta y pulsa **↻ Volver a cargar** en la tarjeta
de la extensión. Si el número de versión no cambia, descomprimiste en el nivel
equivocado — revisa el paso 2.
